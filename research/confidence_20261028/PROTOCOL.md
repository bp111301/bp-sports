# Confidence calibration protocol — 2026-10-28

Registered before results. This experiment addresses probability reliability separately from winner accuracy. Never increase confidence simply to make picks look stronger. Existing models, probabilities, picks, ledgers, and prior evaluations remain unchanged.

One fixed mapping recipe: confidence-space isotonic regression on fixed bins [50,60,70,80,90,100] percent. For each bin, add 100 pseudo-observations centered at the bin's mean raw confidence (bin midpoint when empty), then fit monotone least squares weighted by actual count + 100. Fit using only original-control out-of-fold predictions from the latest three strictly earlier development seasons. Require at least 200 calibration games. Mapping confidence is clipped to [.500001,.999999]; exact raw .5 stays .5. Restore the original selected side, so no chosen winner changes. Report any confidence increases/decreases. No hyperparameter search.

CFB tests exactly two variants: pooled mapping, and P4-v-P4 vs other mapping (SEC, Big Ten, Big 12, ACC, using each historical game's conference labels), with pooled fallback when a group has fewer than 200 prior calibration games. NHL tests pooled mapping only; no retrospective goalie or missingness grouping. Historical control probabilities are the already reproduced original controls from challengers_20261028. CFB evaluates 2019–2025 after 2018 warmup; NHL evaluates 2022–23 through 2024–25 after 2021–22 warmup. Comparisons use exactly the same evaluation games. 2026 live data and NHL 2025–26 are excluded from training and selection. These development data have been reused and are not a fresh holdout.

Eligibility requires lower aggregate Brier and log loss, identical winners, lower or equal fixed-bin ECE, Brier improvement in >=5/7 CFB or >=2/3 NHL evaluation seasons, and no worsening of recent (2023–2025 CFB; 2023–24/2024–25 NHL) aggregate Brier/log loss. No production promotion from historical results. Eligible mappings require a separately frozen prospective shadow and fresh paired outcomes before adoption. Rejections are saved without retuning. Original model win percentages stay raw on the live board; confidence evidence displayed by the UI is descriptive, never presented as a per-game corrected probability.

Read-only confidence UI: settled pregame forecasts only, one row per model/game, never aggregate repeated candidates as independent games. Validate timing, binary outcomes, finite probabilities, and settlement before as-of. Fixed confidence buckets include support counts, predicted confidence, actual win rate and 95% Wilson interval. Fewer than 100 games in a bucket is labeled limited sample. Intervals assume independent games and are descriptive; shared game-day effects and multiple comparisons can make uncertainty larger. No confident/lock label is earned from these summaries. Reject malformed/duplicated data rather than silently using it; show a clear unavailable state.
