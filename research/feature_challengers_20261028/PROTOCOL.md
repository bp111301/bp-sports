# Additional pregame information and denominator-aware rates — 2026-10-28

Registered before new experiment results. Historical development data have been reused in prior experiments; this is hypothesis development, not fresh confirmation. No search, retuning, thresholds changed after seeing results. No live 2026 outcomes or NHL 2025–26 selection labels. Frozen models, forecasts and prior evaluations remain immutable.

## CFB information hypothesis
Original 25% context / 75% k7-prior control and original C=.5 logistic. Test additional source pregame features not in that model: offensive/defensive weighted EPA, third-down percentage, scoring-opportunity rate over expected, starting field position, rush rate over expected, and plays per game. Each is a home-minus-away difference of k7 current/prior blended pregame values, with the existing combine-first rule for missing sides. Add three interaction differences: home attack * away defence minus away attack * home defence, separately for pass EPA, rush EPA, and overall success rate; all operands are k7 blends. No source score, realized player identity, market, game-day weather, or postgame fields may enter the feature matrix.

Exactly two candidates: `expanded_linear` augments BOTH original component feature sets with these 12 rate/context differences and 3 matchup interactions, with original C=.5; `expanded_halfblend` is fixed .5 control + .5 expanded_linear. Target seasons 2018–2025, all training strictly earlier seasons, original guarded source 2015–2025 and identical game cohort (5,733 expected). Feature availability is reported before/after imputation; missing values are never treated as observed zero. Reproduce original control within 1e-12.

## NHL aggregation hypothesis
Original 18-feature indicator logistic comparator. Replace the four per-game percentage means (shooting, saves, PP, PK) with opportunity-weighted, prior-shrunk team rates: shooting goals/shots; save 1-goals-against/shots-against; PP goals/opportunities; PK 1-PP-goals-against/times-shorthanded. Use only each team's latest 20 source games in the current season, with at least 3 valid source games per metric. Use source dates at least two calendar days earlier, conservatively excluding same-day and previous-day outcomes. Invalid/missing numerator or denominator is excluded for that metric, never filled as zero; valid zero opportunities contributes zero opportunities. Allow goals > shots (rare awarded goals) but final rates clipped [0,1]. Shooting/save priors add 100 shots; PP/PK priors add 20 opportunities. Prior mean is the pooled league count ratio from all valid team-games dated >=2 days before the target, with .1 shooting, .9 save, .2 PP and .8 PK only when no positive denominator has yet been observed. Those constants are assumptions, not learned future rates.

Keep original 10 base + four possession/faceoff features, add four shrunk rate differences. New logistic uses C=.5, median imputation WITHOUT indicators to avoid the known missingness confidence sensitivity. Exactly two candidates: `pooled_rates` and fixed .5 control + .5 pooled_rates. Development targets 2021–22 through 2024–25, strictly earlier-season training; original guarded sources through 2024–25 only. Retrospective shot-quality source is not used. Reproduce original control within 1e-12. Record temporal boundaries and missingness.
