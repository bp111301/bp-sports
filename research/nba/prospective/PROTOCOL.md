# NBA V1 prospective protocol

Collect only 2026–27 NBA regular-season games (ESPN ending season 2027, type 2, NBA team IDs 1–30), excluding the non-record Cup championship. No preseason forecasts, grading, or model fitting. Load the existing qualified V1 bundle and verify all frozen hashes and runtime identities. Weights remain trained through 2024–25; 2025–26 and completed 2026–27 outcomes update chronological team state only.

Capture the first eligible snapshot within 36 hours of scheduled tipoff. Forecasts use only earlier Eastern calendar dates, matching development's date batching. Capture time must remain before tipoff after source retrieval and inference. Store features, cutoff, model hash, and source receipt hash. Never overwrite a forecast or backfill games that have started. An hourly run checks source schedules, cross-checks yesterday/today/tomorrow and older pending dates against ESPN scoreboard, and appends completed final results separately. Results require matching teams, non-tied numeric scores, final completion, and valid pregame timing, including a rechecked start. Missing or invalid completed boxes block new forecasts until complete state is available; existing valid predictions can still settle.

`predictions.jsonl` and `results.jsonl` are append-only; `dashboard.json` joins them for the UI and reports prospective accuracy, Brier score and log loss. Historical evaluation remains separate. A postponed game retains its original forecast and receives no replacement. Workflow serialization prevents concurrent writes; pushes fail rather than overwrite divergent ledger histories. No automatic model promotion or tuning.
